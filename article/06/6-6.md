# functions.php での処理

ここでは `functions.php` で行われている処理について紹介していきます。

## 投稿フォーマットの追加

21 行目の `twentytwentyfive_post_format_setup()` という関数内で `add_theme_support()` を使い、投稿フォーマットを追加しています。

ここでは、

- アサイド
- 音声
- チャット
- ギャラリー
- 画像
- リンク
- 引用
- ステータス
- 動画

を追加しています。

- `https://developer.wordpress.org/themes/functionality/post-formats/`

## エディターに editor-style.css を読み込む

36 行目の `twentytwentyfive_editor_style()` という関数内で `add_editor_style()` を使い、エディター用の CSS ファイル `editor-style.css` を読み込んでいます。

- `https://developer.wordpress.org/reference/functions/add_editor_style/`

## フロント用 CSS ファイル style.css を読み込む

51 行目の `twentytwentyfive_enqueue_styles()` という関数内で `wp_enqueue_style()` を使い、フロント用 CSS ファイル `style.css` を読み込んでいます。

- `https://developer.wordpress.org/reference/functions/wp_enqueue_style/`

## ブロックスタイルを登録

71 行目の `twentytwentyfive_block_styles()` という関数内で `register_block_style()` を使い、ブロックスタイルを登録しています。

多くのブロックスタイルは前述しているように `/styles` 内に JSON ファイルを用意して登録していますが、TT5 開発時点で JSON ファイルでは設定できないスタイリングに関しては、このように別途 `register_block_style()` 関数を使って登録しています。

- `https://developer.wordpress.org/reference/functions/register_block_style/`

## 独自のパターンカテゴリーを登録

100 行目の `twentytwentyfive_pattern_categories()` という関数内で `register_block_pattern_category()` を使い、ブロックカテゴリーを登録しています。

デフォルトで用意されているブロックカテゴリーに加えて、

- Pages（スラッグ： `twentytwentyfive_page`）
- Post formats（スラッグ： `twentytwentyfive_post-format`）

が登録されています。

- `https://developer.wordpress.org/reference/functions/register_block_pattern_category/`

## ブロックバインディングソースを登録

WordPress 6.5 から任意のコアブロックとカスタムフィールドを接続することが可能になりました。`register_meta()` で登録したデータを `core/post-meta` で参照してブロックに表示できます。

130 行目の `twentytwentyfive_register_block_bindings()` 関数内で `register_block_bindings_source()` を使い、コアが用意しているブロックバインディングソースとは別に、独自のブロックバインディングソース（カスタムバインディングソースと呼ぶこともある）を登録しています。

その理由としては、カスタムフィールド値ではなく、独自に処理を施したデータ（ここでは投稿フォーマット）をブロックと結びつけるためです。

- `https://developer.wordpress.org/reference/functions/register_block_bindings_source/`

値を得るためのコールバック関数を呼んでいますが、そちらは別途定めています。それが次に紹介する箇所となります。

## 投稿フォーマット名を取得して返すコールバック関数を定義

151 行目の `twentytwentyfive_format_binding()` 関数で、投稿フォーマット名を取得する処理を行なっています。

内部では、

```
$post_format_slug = get_post_format();
```

で投稿フォーマットのスラッグ（`aside` や `gallery` など）を取得します。 次に、

```
if ( $post_format_slug && 'standard' !== $post_format_slug ) {
    return get_post_format_string( $post_format_slug );
}
```

投稿フォーマットのスラッグが取得できており、かつ `standard` ではない場合に、投稿フォーマット名を `get_post_format_string()` を通して返します。

- `https://developer.wordpress.org/reference/functions/get_post_format/`
- `https://developer.wordpress.org/reference/functions/get_post_format_string/`

このカスタムバインディングソースの一連の処理は、今後のブロックテーマ制作・開発において、さまざまなアイデアを提供してくれる大きなポイントになるのではないかと、個人的に考えています。
