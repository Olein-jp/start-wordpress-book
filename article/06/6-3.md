`/assets` には、ブロックエディター用の CSS ファイルやフォントファイル、そしてパターンで利用している画像ファイルが用意されています。

`/parts` にはヘッダーやフッター、そしてサイドバー用のテンプレートパーツが合計 7 つ用意されています。

`/pattern` には 98 ものパターンが格納されています。しかし、それぞれが独立したパターンというわけではなく、構造として入り組んでいます。詳しくは後述します。

`/styles` にはグローバルスタイルやブロックスタイルなどを定義する JSON ファイルが格納されています。`/styles/blocks` にはブロック固有のブロックスタイル、`/styles/colors` にはパレットスタイルが用意されています。`/styles/sections` にはグループブロックやカラムブロックで利用するためのブロックスタイル、`/styles/typography` にはタイポグラフィのプリセットが用意されています。ルートには、グローバルスタイル用の JSON ファイルが用意されています。

`functions.php` には、テーマに必要な機能などが記述されています。後述します。

`readme.txt` には、テーマに関する基本的な情報が掲載されています。

`screenshot.png` は PNG 形式の画像ファイルで、テーマのアイキャチ画像的な存在として多くの場所で利用されます。

`style.css` はテーマのメイン CSS ファイルです。しかし、中身を見るとわかるように記述量はテーマ情報（冒頭コメントアウト部分）も含めて 60 行ほどしかありません。テーマに必要なスタイリングのほとんどは `theme.json` などで行われていることがわかります。

`theme.json` はテーマのグローバル設定やスタイルなどを定義するファイルです。特定の機能の有効・無効を定義したり、スタイリングを JSON 形式で記述し設定します。

# パターン

TT5 には 98 ものパターンファイルが用意されています。大きく分けて５つのグループに分けることができます。

ファイル名に `header-**.php` もしくは `***-header.php` と付けられているパターンはヘッダー用に用意されています。同様に `footer-***.php` と命名されているものはフッター用に用意されたものです。

他にも、１つのページ向けに用意されたものは `page-***.php` と命名されていたり、テンプレート向けのものは `template-***.php` となるように設計されています。そして、インサーターには表示させない形のものは `hidden-***.php` と命名されています。
